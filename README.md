# S.M.V.

**Shrish Mudumby Venugopal** — computational law, systems engineering, institutional design.

I build the instruments — metrics, audits, simulations — that measure whether automated
systems treat people fairly, and the engineering to prove it.

## Highlights

- **Due Process Stress Index** — a framework quantifying due-process degradation in automated
  decision systems across five legal dimensions.
- **CourtListener PR #6703** — merged into the Free Law Project’s production archive;
  ~65× tokenizer speedup (0.22s → 0.003s).
- **Algorithmic Auditor** — HMDA lending-bias pipeline with SHAP explainability and
  counterfactuals.
- **Empirical Evaluation of Cross-Sectional Equity Signals** — published on SSRN.
